## Determinism & edge cases

- Full uptrend window run twice → identical md5
  (`05a376758f3510441c962a8c088ccfbe` both runs).
- Empty stdin → exit 0, no output.
- Mixed input (metadata line, `close`/`c`/`price` keys, `not json`,
  `{"close": null}`, `{"close": -5}`) → 3 valid bars produce 3 `hold`
  lines, everything else ignored, exit 0.
- Broken pipe (e.g. `| head`) handled without traceback.
